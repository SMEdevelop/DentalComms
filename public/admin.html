Message buttons

The big buttons staff tap to send a message. Use the same colour for the same meaning everywhere: terracotta for urgent, sage for ready. The first button here is the first on everyone's screen.

How messages announce themselves

What happens on the screen that receives a message. The same for every room.

Flashing helps where a tablet may be muted or the room is noisy. Blinking the taskbar is for a computer that works in another program all day: use Pop out there, so Dental Comms has its own taskbar button to blink. The first message after that asks for permission to show notifications; allow it. With all three off, a message still appears on screen and waits, quietly.
