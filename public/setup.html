Set up this computer

Do this once per computer. It takes about a minute, and then Dental Flow opens in its own window every morning without anyone touching it.

…

Bookmark the version with a name in it rather than numbers where you can — router restarts change the numbers and break every bookmark in the office at once.

2. Have it open by itself at startup

This downloads a shortcut that opens Dental Flow in its own window — no tabs, no address bar, and nothing to press.

Download the shortcut (Edge) Chrome version
  1. Press Windows + R, type shell:startup and press Enter. A folder opens.
  2. Drag the downloaded Dental Flow shortcut into it.
  3. That's it. Restart the computer to check — Dental Flow should appear on its own.

Want it on the desktop or taskbar as well? Copy the same shortcut there, or right-click it and choose Pin to taskbar.

Why a shortcut rather than the ⧉ Pop out button: browsers only allow a page to open a window when a person clicks something, so that button can never fire by itself at startup. This shortcut asks the browser directly, so nobody has to press anything.

3. Or install it as an app

Same result by a different route — its own icon, its own window. Use whichever you prefer; you do not need both.

In Edge: menu (⋯) → Apps → Install this site as an app. In Chrome: menu (⋮) → Cast, save and share → Install page as app.
Dental Flow is already installed on this computer. Its icon opens it in its own window — put a copy of that icon in the shell:startup folder from step 2 and it will open at sign-in too.
