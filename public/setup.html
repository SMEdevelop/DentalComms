Set up this computer (Edge) Prefer Chrome
  1. Download it. The browser will ask whether to keep it — choose Keep. It is a text file you can open and read.
  2. Double-click Set up Dental Comms in your downloads. Windows may ask whether to run it; choose Run.
  3. It offers to open Dental Comms straight away, so you can see it worked. After that it opens on its own at every sign-in.

Do this on each computer that should open Dental Comms automatically. Either button works whichever browser you have — the setup file uses the one you chose if it is installed, and the other if it is not. To undo it, delete the Dental Comms shortcut it puts in your Startup folder.

Why a setup file rather than the shortcut itself: browsers refuse to save Windows shortcuts and rename them to .download, so the shortcut has to be made here rather than sent. And why a shortcut rather than the ⧉ Pop out button: browsers only allow a page to open a window when a person clicks something, so that button can never fire by itself at startup. This shortcut asks the browser directly, so nobody has to press anything.

3. Or install it as an app

Same result by a different route — its own icon, its own window. Use whichever you prefer; you do not need both.

In Edge: menu (⋯) → Apps → Install this site as an app. In Chrome: menu (⋮) → Cast, save and share → Install page as app.
Dental Comms is already installed on this computer. Its icon opens it in its own window — put a copy of that icon in the shell:startup folder from step 2 and it will open at sign-in too.
