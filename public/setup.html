Open it by itself at startup?

This downloads a small setup file. Run it on this computer and Dental Comms opens by itself in its own window at sign-in, with no tabs, no address bar and nothing to press.

Use Chrome instead Set up this computer
  1. The browser asks whether to keep the file: choose Keep. It's a text file you can open and read.
  2. Double-click Set up Dental Comms in your downloads. If Windows asks whether to run it, choose Run.
  3. It offers to open Dental Comms straight away, so you can see it worked. After that it opens on its own at every sign-in.

Either button works whichever browser you have: the file uses the one you chose if it's installed, and the other if not. To undo it, delete the Dental Comms shortcut it puts in your Startup folder.

More details

Why a setup file rather than the shortcut itself: browsers refuse to save Windows shortcuts and rename them to .download, so the shortcut has to be made on this computer. And why not the Pop out button: browsers only open a window when a person clicks something, so that button can never work by itself at startup. The shortcut asks the browser directly, so nobody has to press anything.

Or install it as an app?

The same result by a different route: its own icon and its own window. Use whichever you prefer; you don't need both.

In Edge: menu (⋯), then Apps, then Install this site as an app. In Chrome: menu (⋮), then Cast, save and share, then Install page as app.

Dental Comms is installed on this computer. Its icon opens it in its own window. Put a copy of that icon in the shell:startup folder and it opens at sign-in too.
